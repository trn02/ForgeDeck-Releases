# ForgeDeck Releases

Ebben a repóban kizárólag a ForgeDeck kész, hordozható Windows-kiadásai vannak.
A program forráskódja, kezelt webprojektjei, jelszavai és helyi adatai nem
részei a kiadásoknak.

Az első telepítéshez töltsd le a **Latest** jelölésű teljes kiadás
`ForgeDeck-win-x64.zip` fájlját, csomagold ki, majd indítsd el a
`ForgeDeck/ForgeDeck.exe` fájlt. A részfrissítések kisebb, prerelease-ként
jelölt csomagok: ezeket nem kell kézzel letölteni vagy kicsomagolni.
A ForgeDeck a teljes alapkiadás után az `update-history.json` alapján
megszámolja és sorrendben telepíti az összes hiányzó részfrissítést.
Az `update-manifest.json` a régebbi kliensek számára a legújabb teljes
alapkiadást tartja elérhetően.
