# ForgeDeck Releases

Ebben a repóban kizárólag a ForgeDeck kész, hordozható Windows-kiadásai vannak.
A program forráskódja, kezelt webprojektjei, jelszavai és helyi adatai nem
részei a kiadásoknak.

Az első telepítéshez töltsd le a legújabb Release `ForgeDeck-win-x64.zip`
fájlját, csomagold ki, majd indítsd el a `ForgeDeck/ForgeDeck.exe` fájlt.
Frissítéskor a program az `update-manifest.json` fájlból olvassa ki az új
kiadás ZIP-címét és SHA-256 ellenőrzőösszegét.
